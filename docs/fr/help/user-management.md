*Note : Cette page contient du contenu fictif illustratif.*

## Ajouter un utilisateur manuellement

En tant qu'administrateur, vous pouvez ajouter des utilisateurs manuellement.

### Prérequis
* Vous devez être connecté en tant qu'Administrateur Entreprise.

### Procédure
1. Dans la console, allez dans **Répertoire > Personnel**.
2. Cliquez sur **Créer un utilisateur**.
3. Saisissez les détails et attribuez un rôle.
4. Cliquez sur **Enregistrer**.
